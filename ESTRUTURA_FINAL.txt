🎯 PRÓXIMOS PASSOS:

1. Criar ambiente virtual:
   python -m venv .venv

2. Ativar ambiente:
   .\.venv\Scripts\Activate.ps1  (Windows)
   source .venv/bin/activate      (Linux)

3. Instalar dependências:
   pip install -r requirements.txt

4. Usar o sistema:
   python src/transcribe.py
